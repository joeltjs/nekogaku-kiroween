# Working rules for this repo

- The `nekogaku` skill in `.kiro/skills/nekogaku/` describes the haunted house. Read it before touching `game/`.
- Three cats only (Cecil, Kuku, Bolu); one room; English UI; EXP and Love only; arcade time.
- Only original or openly licensed assets. Cats, items and costumes are drawn by our rig and painters.
- Nothing personal in the repo: no real names, accounts, dates of people's lives, private notes or paths.
  Access codes are never committed; they live only in the database.
- Never commit or push on the author's behalf; leave no dev server running.
- The earlier project is read-only for this build (the `guard-source-project` hook enforces it).
